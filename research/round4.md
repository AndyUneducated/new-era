## 分工防撞（必须遵守）

- **中委档案（K03–K06）按“首次进入中委或候补的届别”分人**：一个人第一次出现在第 X 届名单（`content/congresses/K01.yaml` 里第 X 届的 `cc` 或 `cca`），就归负责第 X 届的批次。用 `research/scripts/K0x-*.ts` 读 K01.yaml 算出本批次名单，减去 `content/people/` 里已有的姓名（注意少数民族全名、同名同姓），就是你要建卡的人。
- **落马批次（T01、T02）只收不在任何一届中委 / 候补名单上的人**（副省级、副部级、央企、金融机构、军队将领中的非中委……）。落马的中委、候补由 K 批次建卡并写 `fall`。
- **P01、P02、E07–E09、R01 不建人物条目**，需要的人在回报里列出。

## K03–K06 中央委员、候补中央委员档案卡

- **K03：** 首次出现在第十六届名单的人（约 266 人）。
- **K04：** 首次出现在第十七、十八届的人（约 287 人）。
- **K05：** 首次出现在第十九届的人（约 172 人）。
- **K06：** 首次出现在第二十届的人（约 205 人）。

每人一张 tier 2 档案卡（`content/people/<批次>.yaml`，登记 `research/roster/<批次>.yaml`）。字段：`name`、`born`、`birthplace`、`gender`、`ethnicity`（非汉族时）、`roles`（`cc` 或 `acc`，曾任省级主官加 `prov`，部长级加 `minister`，将领加 `general`，落马加 `tiger`）、`headline`、`bio`（1–2 句）、`positions`（3–6 条最高的几个职务，地方职务写 `place`）、`status`、`fall`（如有）、`ids.wikidata`、`cites`。

- **批量做法：** 用脚本按姓名查 Wikidata（`node tools/fetch-wikidata.ts --find --out=<批次> 名字…`，可分批），**按描述与职务确认是同一人**（同名同姓很多：核对出生年、籍贯、任职），再抓记录（`node tools/fetch-wikidata.ts Q…`）。Wikidata 的生卒、出生地、职务可以直接用（`cites` 里写 `wd-Q…`），再加该届名单来源（K02 已登记：`k02-xinhua-…-cc` / `-cca`）。
- **落马者必须查清：** 中纪委“审查调查”通报、新华社开除党籍消息、判决消息（`voice: official` 或 `doc`），写 `fall` 每一步并把 `status` 改为 `purged` / `detained`。落马是本轮的重点之一，**不要漏**：对每个人在中纪委网站或新华社搜一次姓名 + “严重违纪违法”“接受审查调查”。
- 去世的写 `died` 与 `status: dead`（可靠来源）。退休的写 `retired`。
- Wikidata 查不到的，用人民网“中国共产党新闻网·领导人资料”简历、新华社任免消息、省政府网简历；都没有的列入回报，不要编。
- 有媒体派系标签的照样写 `factions`（多数人没有，不必刻意找）。
- 目标：本批次名单全部建卡；做不完的按“二十大在任 → 落马 → 其余”的优先级，回报写剩余名单。

## R01 传闻专项（明显标注）

用户要求：“本项目其他页面都接收非官方数据、小道消息，但是明显标注即可。一定要丰富内容！”本批次做四个专题，事件写 `content/events/R01.yaml`，人物层写 `content/assess/R01.yaml`，家属与财富写 `content/assess/R01.yaml`（带“家族财富”字样）：

1. **北戴河会议：** 2003–2026 年历年北戴河会议的报道与传闻（日经中泽克二、明报、RFA、大纪元等），每年一条（找不到的年份不写），`lane: power`。
2. **健康传闻：** 江泽民“去世”误报（2011）、胡锦涛、习近平（2012 “背伤”、2024 中风传闻、2025 前后各种说法）、李克强、温家宝等，`summary` 第一句写清谁传出的，并列官方或可靠媒体的反证。
3. **政变与权斗传闻：** 2012 “3·19 政变”、2015 “刺习”、2022 “软禁”谣言（9 月）、2024–2026 “军队兵变”“张又侠逼宫”等；同上并列反证。已有的（E06 写过）Grep 后不要重复，补 voices 的在回报里列。
4. **家族财富：** 主流调查报道（纽约时报 2012 温家宝家族、彭博 2012 习近平家族、ICIJ 2014 离岸解密、2016 巴拿马文件、2021 潘多拉文件涉及的高层亲属）＋传闻来源的补充。写进对应人物的 `assess`（`text` 写清“据某某报道……”，有当事方回应的并列）。

传闻来源一律 `rumor: true`。不改任何人的 `status`、`fall`。
