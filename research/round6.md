# 第六轮批次（M7：落马收全与案件结构化；彩色照片）

8 个批次并行。共同规则见 `research/agent-brief.md`、`research/howto-content.md`（本轮看 §1、§2、§3、§4 档案卡、**§10 落马案件**、**§11 照片批次**）。用户的新要求见 `research/decisions.md` 第三次调整（#36–#54）。

已整合：1624 人（完整传记 123），其中有落马记录的 437 人；6400 多个来源。批次模式下全部可见、可引用。**先 Grep 已有来源，再登记新的**。

## R01–R06：按年份收全中管干部落马者

范围：**2012-11 以来中央纪委国家监委通报的中管干部**（省部级正副职、中管企业和金融机构领导、中管高校领导等），按**第一次公开通报（立案审查或接受组织调查）的日期**分给各批次，不重不漏。军队（军委纪委、军事检察院、罢免军人人大代表）不在本轮，留给下一轮的军队批次；武警、公安现役的照样算地方。

| 批次 | 第一次通报的日期 |
|---|---|
| R01 | 2012-11 至 2014-12 |
| R02 | 2015 |
| R03 | 2016 至 2017 |
| R04 | 2018 至 2020 |
| R05 | 2021 至 2023 |
| R06 | 2024 至今 |

步骤：

1. **名单。** 先找完整名单：中央纪委国家监委网站“审查调查 · 中管干部”栏目（`ccdi.gov.cn`，按年份翻页），或维基百科“中共十八大以来落马的省部级以上官员列表”一类的年表页（`voice: wiki`，`excerpt: true`，`keep` 写你那几年的行）。把范围内全部人员写进 `research/falls-list/<批次>.yaml`：`- { name: 某某, date: 2015-03-15, post: 落马时职务, id: 已有条目的 id 或空, done: false }`。已有条目的人 Grep `content/people/` 找 id（注意同名）。
2. **新建档案卡**（§4 档案卡标准，写进 `content/people/<批次>.yaml`，登记 `research/roster/<批次>.yaml`，`roles` 含 `tiger`）：先做职级高的。每张卡：`positions`（3–6 条，到落马时的职务）、`status`、`fall`（每步一条：通报立案、开除党籍、判决；判决写明罪名、刑期、金额）、`bio` 1–3 句、`cites`。**同时**为他写 `content/falls/<批次>.yaml` 的案件记录（§10）。
3. **补已有的人。** 范围内已经有条目、但还没有案件记录的人（除宋亮外都没有），写 `content/falls/<批次>.yaml`：`sys`、`grade`、`notice`、`discipline`、`amount`、`trigger`、`with`、`politics`；卡上缺开除、判决的，用记录里的 `fall` 补上，状态随之改（判刑后为 `detained`）。
4. **数量。** 新卡与案件记录合计**做到 80 人左右就停**（宁可少而准），没做完的在名单文件里 `done: false`，下一轮接着做。边做边存文件，每做完 10–15 人跑一次 `node tools/build-data.ts --batch=<批次>`，以免中途中断丢失。
5. **通报全文**（中纪委网站、新华社）是官方文件，全文入库；判决消息同。同一人的立案、开除、判决三条消息通常各是一个来源。

## PH1、PH2：彩色照片

各一份清单：`research/photo-PH1.md`、`research/photo-PH2.md`（各 180 人，按优先级排：完整传记、政治局、中委、落马者……）。标“现为黑白”的是已有照片但为黑白，要换成彩色。按 §11 找图、下载、压缩、核对，写进 `content/photos/<批次>.yaml`。**做到 120 人左右或清单做完就停**，回报里列出找不到照片的人。
