# 方法

## 1. 来源与登记

每份来源在 `research/manifests/*.yaml` 的 `web:` 下登记一条：

```yaml
- id: xinhua-2022-10-23-pb          # 稳定 id，全站引用用它
  title: 中国共产党第二十届中央委员会第一次全体会议公报
  publisher: 新华社
  date: 2022-10-23
  voice: doc                         # 见 §2
  url: http://www.news.cn/...
  start: ...                         # 可选：正文起止标记
  end: ...
  excerpt: true                      # 有版权的来源只存摘录
  keep: [蔡奇, 之江]                  # 摘录：保留含这些字符串的段落
```

`npm run data:fetch` 抓取后写 `sources/text/<id>.txt`，并在 `research/fetch-log.jsonl` 记一行（时间、网址、整页 SHA-256、字数）。整页 HTML 只留在本地（`sources/raw/`，不提交）。抓不到的页面用 Wayback 快照，`url` 写快照地址。

Wikidata 记录（CC0）由 `npm run data:wikidata` 写 `research/wikidata/*.json`，作为档案卡的出生、籍贯、职务等基本事实的来源（`cite: wd:Q15031`）。

## 2. 声部

| voice | 含义 | 例 |
|---|---|---|
| `doc` | 官方文件原文 | 党章、公报、党代会报告、政府工作报告、名单 |
| `official` | 官方媒体与机构报道 | 新华社、人民日报、中纪委网站、人民网领导人资料 |
| `history` | 后来的官方定性 | 第三个历史决议、党史 |
| `west` | 西方主流媒体 | NYT、WSJ、FT、Reuters、Bloomberg、Economist、AP、Guardian |
| `japan` | 日本媒体 | 日经（含中文网）、朝日、共同社 |
| `zh` | 港台新加坡及外媒中文版 | BBC 中文、DW、RFA、VOA、联合早报、明报、端、中央社、FT 中文网、纽约时报中文网 |
| `scholar` | 学者 | Brookings、China Leadership Monitor、学术论文与专著 |
| `witness` | 当事人或亲历者 | 本人采访、回忆录、庭审陈述 |
| `wiki` | 维基百科与 Wikidata | 只作基本事实的辅助来源，不作派系判断的依据 |
| `site` | 本站 | 由库内材料推出的整理 |

派系标签只接受 `west`、`japan`、`zh`、`scholar`、`official`。2026-10-14 起（decisions #27），大纪元、看中国、新唐人、博讯、明镜、多维、自媒体等传闻来源也收，登记时加 `rumor: true`，页面标“传闻”；落马、去世等状态与落马经过只用可靠来源。细则见 `howto-content.md` §2。

## 3. 引文核对

- 名言 `quotes`、派系标签的支持句 `quote`、标为引文的评价 `quote: true`：构建时在出处文本里逐字查找。
- 允许：`……` 分段省略；句末标点差异；单双引号互换。其余必须一字不差。
- 外文引文以原文核对，`zh` 字段是本站译文，不参与核对。

## 4. 名言的五类

| kind | 含义 | 页面标注 |
|---|---|---|
| `public` | 公开讲话、署名文章原文 | — |
| `adlib` | 即兴发言，有视频或权威报道 | 即兴 |
| `interview` | 外媒采访、记者会原话 | 采访 |
| `leaked` | 泄露或转述的内部讲话 | 转述 |
| `rumor` | 民间流传、真伪存疑 | 流传，未经证实 |

`leaked` 与 `rumor` 的出处是刊载这一说法的文章；核对的是“文章这样写了”。

## 5. 版权

- **官方文件**（法律法规、国家机关的决议决定，及党章、党代会报告、全会公报等党的正式文件）：全文入库。依据是《著作权法》第五条对“国家机关的决议、决定、命令和其他具有立法、行政、司法性质的文件”的排除；党的文件比照处理，这是本站的解释。
- **媒体、学者、维基百科**：只存摘录，每份来源保留的段落以支撑引文为限。
- **照片**：Commons 图像照录许可；官方标准像存本地，许可写“版权归原发布机构”，并注明原始网址（decisions #9）。

## 6. 在世人物

- 履历、公开言论、官方处分：照写。
- 家属与财富：只写主流媒体调查报道，写明媒体、日期，并列当事方回应（如有）。
- 下落不明、调查传闻：只写“某媒体报道”，不写成事实；官方确认后改写。
